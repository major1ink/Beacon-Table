Десктопная версия, этажи, чат за столом, 3D-кубы.

- Десктопная версия: стол в своём окне вместо браузера — Windows (`.exe`), macOS (`.zip`, universal), Linux (`.deb` и `.rpm`). При запуске — стол на этом компьютере или подключение к серверу; данные в выбранной папке, по умолчанию «Документы/Beacon Table». Окно трансляции для телевизора открывается из окна ДМ, на Windows само встаёт на второй монитор во весь экран. Трей: адрес для игроков, папка стола, выключение; крестик прячет окно в трей или закрывает программу — как выбрано в настройках.
- Этажи: здание из сцен, переключатель этажей, перенос токенов между этажами, телепорты между этажами, импорт Foundry Levels.
- Сцены: открытая у ДМ больше не становится активной для игроков — кнопка «Показать игрокам»; зона показа игрокам; доступ игрокам к разрешённым сценам.
- Чат за столом: общий и личный, вкладка в окне бросков.
- Броски: 3D-кубы со звуком поверх карты и на трансляции, видны на всех экранах; скрытые броски ДМ.
- Призыв существ игроком: запрос ДМ → токены рядом с игроком; ПКМ по своему токену — статблок, состояния, зрение, свет.
- Режим обучения: тур по столу при первом входе, тумблер в настройках.
- Оптимизация и исправления графики, добавлен счетчик fps (тумблер в настройках).
